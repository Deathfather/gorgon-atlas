# Gorgon Atlas v0.3.3

The first public release.

## Highlights

- 59 selectable overworld, dungeon, cave, sewer, and special-event areas
- 1,347 public enemy-location records, including 241 boss records
- 263 friendly and service NPCs with published positions
- Searchable filters, favorites, local notes, personal markers, and routes
- Always-on-top, opacity, global show/hide, and recoverable click-through controls
- New Gorgon Atlas desktop, taskbar, and in-app icon
- Eltibule duplicate-marker crash fixed

## Install

1. Download `GorgonAtlas-v0.3.3.zip` below.
2. Extract the entire folder.
3. Run `GorgonAtlas.exe`.

Windows may show an unknown-publisher warning because this personal build is not code-signed. Administrator rights are not required.
