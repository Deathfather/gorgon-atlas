# Gorgon Atlas

Gorgon Atlas is a searchable, always-on-top Windows companion map for **Project: Gorgon**.

It covers enemies, bosses, friendly NPCs, landmarks, portals, dungeons, favorites, private notes, personal markers, and simple waypoint routes. It does not attach to the game, read memory, intercept traffic, automate input, or modify the client.

## Download

Download the latest compiled player build from [GitHub Releases](https://github.com/Deathfather/gorgon-atlas/releases/latest).

1. Download `GorgonAtlas-v0.3.4.zip`.
2. Extract the entire folder.
3. Run `GorgonAtlas.exe`.

Keep the bundled `Data` and `Assets` folders beside the executable.

## Website

Visit the [Gorgon Atlas project page](https://deathfather.github.io/gorgon-atlas/) for screenshots, feature details, installation help, and accuracy notes.

## Data accuracy

Friendly NPC and landmark coordinates come from Elder Game's public third-party data. Enemy spawn coordinates are not present in that feed, so enemy and boss entries use written location records from the Project: Gorgon Wiki. Approximate and area-wide enemy pins are labeled accordingly.

The current build provides 81 selectable areas, 311 positioned NPCs, 279 unique official map markers, and 1,347 public enemy-location records. Its area catalog combines the Wiki's public Zone and Dungeon categories with official area and NPC names, so peaceful locations are not omitted merely because they have no enemies.
